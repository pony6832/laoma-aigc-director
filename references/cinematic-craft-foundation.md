# 通用電影鏡頭基礎

本層吸收 `director-craft-framework` 可跨平台使用的方法，負責把劇本與抽象情緒轉成攝影機可看見、麥克風可聽見、生成後可檢查的導演規格。它先於導演風格鏡頭；即使不指定導演也必須使用。

## 調用

先以需求關鍵詞查詢少量方法：

```powershell
python scripts/query_cinematic_grammar.py "角色很緊張但表演空泛"
```

依結果只載入需要的方法，不把八項全部堆入單鏡提示。完整逐鏡仍要通過九維檢查：鏡頭任務、畫面構成、光影構造、運鏡調度、表演身體地圖、動作設計、對白與聲畫調度、場景物理回饋、攝影器材與技術結果。

## 工作順序

1. 從本案劇本找出人物目標、障礙、開始狀態、轉折動作與結束狀態；每鏡只承擔一項主要任務。
2. 用「情境、機位、焦段、運動、時機」五元組決定鏡頭。景別說明情緒距離，角度說明權力，焦段說明空間壓縮或擴張。
3. 構圖寫明主體位置、視線方向、留白、遮擋與前／中／背景；不以「電影感」代替。
4. 光影依序寫光源動機、方向、質感、色溫與對比，並說明它如何作用在人與空間。
5. 運鏡必須服務揭示、跟隨、施壓、逃離、失衡或反轉；沒有動機就固定。高階技法拆成基礎運動、焦段、速度和時機。
6. 把情緒改寫成臉、眼、嘴、呼吸、手、肩、重心、停頓、道具與聲音的身體地圖。
7. 對白綁定說話者、對象、動作、停頓、打斷、口型、畫內外聲、環境遮蓋與沉默反應。
8. 動作／追逐／特效寫目標、障礙、路徑、發力點、反應半拍、攝影機參與、環境與光影回饋、結束姿態。
9. 器材名稱與數值只有在能說明可見結果且入口可執行時才保留；無法證明就寫光學與運動效果，不堆品牌。

## 與導演風格及平台的關係

- 未指定導演：本層直接建立可執行鏡頭；可再依題材推薦 1–3 位導演鏡頭，未獲授權不默默鎖定。
- 已指定導演：本層保證可拍與連戲，單一導演鏡頭只改變作者選擇，不得覆蓋案件鎖定。
- 平台轉譯：完成平台中立導演母版後，才由最新 Seedance、Kling、H3、ComfyUI 或 Higgsfield 路由轉譯。此來源 2026-06 的平台能力判斷未匯入。

## 驗收

抽象形容詞若沒有可見／可聽證據即退回重寫。逐鏡先檢查敘事任務與連戲，再檢查九維；只有與實際輸出 timecode 對得上的證據才能進 Gate 4。
