# 導演風格鏡頭路由

本層把導演姓名轉譯成可觀察、可測試的創作變數，不把姓名直接當成提示詞。風格鏡頭只提供 Gate 3 的美學方法；老馬 AIGC 導演的 Gate、權利、連戲、平台路由與最終 QC 仍是最高執行權限。

## 使用規則

1. 先讀 `director-styles/catalog.json`，依姓名、別名或使用者明確指定選擇；一次只載入一個導演鏡頭。若使用者要求混合，先各自拆出特徵，再由使用者核准一份新的混合規則，不能同時把多份模組全文塞進提示詞。
2. 把模組轉譯為五軸：敘事結構、鏡頭與構圖、燈光與色彩、剪輯節奏、聲音與表演。只採用與本案故事目的相符的軸。
3. 低順位風格不得覆蓋 PROJECT_STATE.json、`PRODUCTION_BIBLE.md`、`CHARACTER_PROFILE.json`、核准分鏡、權利限制或實際平台能力。
4. 不得複製特定電影的鏡頭、台詞、角色或情節；不得聲稱作品就是某位在世導演的新作。輸出應描述高階電影語法與本案原創選擇。
5. 模組內精確焦段、光比、秒數等數值，若沒有獨立一手或可信來源，只能作為短測假設，不可寫成史實。

## Gate 接入

- Gate 1：可用鏡頭提出方向候選，但標示為創作假設，不鎖定人物或情節。
- Gate 2：風格只能調整視覺測試條件，不可破壞角色、場景與連戲鎖定。
- Gate 3：在逐鏡表記錄選用鏡頭、五軸設計、反例與驗收點；先做同場景 A／B 短測，再核准批次生成。
- Gate 4：使用 `assets/director-style-review-template.md` 對實際成片審片。五軸至少 3／5 有具體可見或可聽證據，且沒有違反鎖定與禁用項，才可判 `STYLE_LOCK_PASS`。風格通過不等於整片 QC 通過。

## 可辨識性邊界

「一看就知道」是待驗證的觀眾反應，不能由文字規格保證。先以固定故事、人物、場景與時長做對照測試，只變動一個風格鏡頭；再以盲測或至少兩位審查者的逐軸證據判斷。若只有色調或一個表面效果相似，判為 `STYLE_DRIFT` 或 `INSUFFICIENT_EVIDENCE`。
