# 知識路由

只讀取當前案件需要的專科，不將無關案例、提示詞或素材帶入案件。

| 觸發條件 | 讀取專科 |
| --- | --- |
| 需要建立角色事實、外觀或定裝連續性 | 角色／定裝 |
| 需要定義敘事、節奏、台詞或劇本 | 故事／劇本 |
| 需要設計鏡頭語言、場面調度或分鏡 | 攝影／分鏡 |
| 要產生或診斷 Seedance 鏡頭 | Seedance |
| 要產生或診斷 MiniMax H3 鏡頭 | H3 |
| 要建立節點式影像或影片流程 | ComfyUI |
| 需要旁白、音樂、音效、混音或交付後製 | 聲音／後製 |

同一案件跨專科時，以已核准的 PROJECT_STATE 與鎖定版本作為交接輸入。
