# 老馬 AIGC 導演方法快照 V1

- 快照版本：`director-methods-v1.0.0`
- 同步日期：2026-09-02
- 用途：讓已安裝 Skill 不依賴其他技能資料夾，也能完成 Gate 1–4 的規劃、生成交接、QC 與復原。
- 邊界：本文件只固定可移植方法，不保存舊案角色、故事、私人素材、專屬提示詞或未經當前入口重查的產品規格。

## 共同起點

### 一個點子

把點子整理為：一句話概念、目的、受眾、平台、時長、比例、主體、衝突／展示目標、情緒曲線、結尾畫面、聲音需求、權利狀態。資料不完整時，先做明示假設與一版 brief；只有會改變方向、權利或大量成本的問題才阻擋。

### 一張圖

1. 先確認檔案可讀與權利範圍。
2. 分列可直接觀察的主體、外觀、服裝、材質、場景、光線、構圖與比例。
3. 把看不見的年齡、職業、個性、故事或品牌意圖標成創作推定，不當成事實。
4. 為每張參考圖指定單一主要職責：身分、服裝、場景、風格或構圖；明寫不可轉移的內容。
5. 先核准主視覺或最小測試，再擴大角色包、分鏡或影片生成。

### 一項製作需求

先判斷要實際製作、局部修正、共同導演或導師模式。製作需求直接建立 Gate 對應產物；教學需求才拆成診斷、示範、練習與回饋。若使用者只要求局部修改，只碰指定版本／鏡頭，保留其他雜湊。

所有產物都標示：`已觀察`、`創作推定`、`待決定` 或 `已鎖定`。只有來源證據或使用者核准可成為已鎖定事實。

## 角色與影像鎖定

### CHARACTER_PROFILE 最低內容

- 身分：名稱、虛構／本人／已授權類型、辨識錨點。
- 外觀：臉型、眼距、眉、鼻、嘴、下巴、髮際與髮型輪廓、體態比例、膚色或物種特徵。
- 定裝：服裝層次、材質、顏色、配件、鞋履、道具及不可變項。
- 表演：核心氣質、姿勢、視線、呼吸、表情幅度與動作風險。
- 參考分工：每張素材的唯一職責、不得轉移內容、來源 SHA-256 與權利狀態。
- 版本：草稿、核准狀態、鎖定欄位與新版本原因。

沒有角色檔就先建立 draft；不可把推定欄位寫成使用者已確認。真人或聲音權利不明時，不下載、不仿製、不生成，停在 Gate 1／2 並提出原創替代方案。

### 角色總覽板

角色總覽板與角色檔是不同產物。建議使用乾淨底色與足夠留白，至少包括：

- 角色名、職能、核心氣質與視覺標誌。
- 一個最大的英雄姿態。
- 正面、背面、側面、四分之三與數個自然／動作全身姿勢。
- 至少四個可辨識剪影與四種保持同一五官的表情。
- 臉部、髮型、服裝層次、手部、鞋履、道具與材質細節。

圖片內只放短標題；精確長文保留在 Markdown 與 JSON。生成後檢查同一身分、比例、服裝、手部、道具、格數與可讀性，將實際檔案與 SHA-256 以 `character_overview_board` 鎖定。

### 無角色場景參考板

另做一張不含角色的場景板；不可用角色總覽板或視覺分鏡代替。場景板鎖定：

- 空間格局、入口／出口、人物未來可行走區域與 180 度軸線。
- 主光方向、色溫、時間、天氣與可見動機光。
- 牆面、地面、布料、金屬、玻璃、液體等材質反應。
- 主色、輔色、對比與環境狀態變化。
- 不應出現的人物、品牌、文字或舊案元素。

生成後以 `character_free_scene_board` 鎖定實際檔案與雜湊。

### 4–6 秒一致性短測

先選一個最能暴露風險的短測；真人／高一致性角色可依序測正面說話、側面轉頭、遠景走近。每次只測一個主要動作與一個主要運鏡，固定角色、服裝、場景、光線、比例與入口設定。

必查：身分、服裝／道具、空間、動作接觸、手部／解剖、鏡頭路徑、光線、聲畫同步及結尾姿勢。通過後在 `02_character_and_look/` 保存非空 MP4／MOV，從容器驗證實際 4–6 秒時長，並保存入口、設定、QC 與 SHA-256，以 `consistency_test` 鎖定；文字／空檔、計畫書、prompt、job ID、排隊畫面或只填宣告時長都不等於短測輸出。

## 導演與攝影

### 每鏡五問

1. 這一刻觀眾必須知道、感到或懷疑什麼？
2. 人物、視線、道具與空間關係如何改變？
3. 鏡頭為何因事件而移動；若固定，畫面內有什麼變化？
4. 節奏是蓄力、停頓、爆發、餘韻還是資訊交代？
5. 上下鏡的方向、姿勢、光線、道具、焦點與聲音如何銜接？

每鏡輸出固定欄位：

```text
敘事用途｜時間碼｜人物走位｜起始與結尾狀態｜景別／焦段｜構圖與焦點｜運鏡方向／幅度／速度／停止點｜光線／材質｜表演｜聲音｜連續性護欄｜可執行提示詞｜驗收條件
```

### 動作與物理

使用可觀察因果鏈：

```text
初始姿勢 → 觸發 → 主動作 → 身體反作用 → 環境／材質反應 → 最終姿勢
```

檢查重心、接觸時點、重量、慣性、遮擋、布料／液體延遲反應。不要只寫「自然動作」。複雜互動先退回單人、單鏡、單一接觸與 4–6 秒。

### 鏡頭選擇

- 固定中遠景＋負空間：等待、孤立或讓觀眾搜尋資訊；畫面內必須有事件。
- 動機式跟拍：角色先起步，鏡頭後啟動；角色停下時鏡頭可晚半拍停。
- 受限環繞：只繞四分之一或半圈，用關係／物件重心變化支持敘事。
- 俯視／垂直揭示：交代規則、空間或後果；先確定場景配置。
- 固定鏡位轉焦：一次只轉一個焦點，不同時加入大幅運動與快速動作。
- 前景遮擋揭示：遮擋必須來自場景，藉小位移露出資訊。
- 有限手持：微晃服務壓力或即興，情緒爆發後短暫收穩。
- 長鏡頭調度：只安排兩到三個可讀走位節點；多人先短測。
- 主觀鏡＋反應鏡：視線高度、方向和上一鏡一致。
- 反射構圖：先確認鏡面左右與焦點層次。
- 甩鏡／匹配轉場：只服務一個方向或形狀，不掩蓋動作錯誤。
- Dolly zoom：只在空間認知翻轉時短促使用，先用單人、清楚背景線短測。

不可用在世導演姓名要求模仿。研究作品時只採「可見觀察 → 敘事功能 → 用不同角色與場景做變形練習」。

### 多鏡連戲

保留人物位置、視線、行進方向、道具出入、天氣、光源與時間；以前一鏡結尾姿勢接下一鏡起始。需要跳接時把它設計成明確風格，不讓意外漂移冒充風格。

## Seedance 路由

執行前先在使用者實際入口確認模型名稱／版本、支援素材、時長、比例、解析度、費用與地區；不要把快照、另一版本或第三方包裝的數字當成現況。

### 選擇工作流

- 從概念探索：T2V。
- 鎖定人物、產品或首幀：I2V。
- 控制開始與結束構圖：首尾幀（仍須驗證中間動作）。
- 移植動作、運鏡、風格或節奏：多模態參考，逐份寫唯一職責與禁用轉移。
- 延長或修改既有片段：只有入口明確提供相應功能時採用，保留原片與新版本。

### 提示結構

```text
作品目的與輸出規格
角色／產品／場景與不可變項
參考素材逐項職責與禁用轉移
按時間的敘事用途、人物走位、可見動作與物理因果
構圖、焦點、鏡頭方向／幅度／速度／停止點
光線、色彩、材質
對白、Foley、環境與音樂的來源及同步點
上一鏡起點、下一鏡結尾與連續性護欄
可驗證結尾狀態與 QC
```

4–6 秒只放一個主體、一個主要動作、一個主要運鏡與一個情緒變化。長內容拆成節拍；每一段明寫起點與結尾。無法驗證的形容詞刪除，不靠大量否定詞掩蓋衝突。

## MiniMax H3 路由

先分清三件事：模型能力、實際平台／API 入口、ComfyUI 節點。只根據當前官方文件與實際入口填寫支援項目；不能因節點名稱存在就說模型已在本機運算，也不能把輸入限制改寫成輸出規格。

### 多模態參考分工

| 素材 | 可分配的單一主要職責 | 不應自動轉移 |
|---|---|---|
| 圖片 | 人物身分、商品幾何、服裝、場景、構圖或風格 | 其他圖的角色、背景、文字或品牌 |
| 影片 | 動作、運鏡、剪輯節拍、物理反應或場面調度 | 原片人物、商品、場景或音軌 |
| 音訊 | 音色、說話速度、節奏、環境質感或能量 | 未授權聲紋、歌詞、旋律或錄音內容 |

提示使用實際入口顯示的引用名稱與連接順序；逐項寫「只參考」與「不得帶入」。不要在權利不明時使用可辨識真人聲紋或音樂。

### 全模態提示結構

```text
作品目的｜輸出意圖｜目標內容與不可變項｜每份參考職責｜禁用轉移｜時間節拍｜表演與嘴型｜聲音事件及空間方向｜結尾狀態｜逐項驗收
```

把聲音事件綁定可見動作與時間點，例如接觸瞬間的 Foley；不要在畫面提示末尾只加「有音效」。先用較低成本／較短設定驗證內容、動作與聲音，再在入口明確支援且使用者核准後升級；升級後重新驗收，不把高解析度當成內容不漂移的保證。

## ComfyUI 路由

### 四層判斷

| 層級 | 意義 | 必查 |
|---|---|---|
| Core／內建節點 | 隨 ComfyUI 維護的基礎節點 | ComfyUI 版本、節點名稱、資料型別 |
| Partner/API 節點 | 呼叫外部服務 | 帳號、credits、網路、服務版本、資料外傳 |
| 第三方 custom node | 社群可執行擴充 | 作者、repo、授權、commit、依賴、網路行為 |
| 模型／服務 | 真正生成或處理媒體的系統 | 模型卡、權重／API、授權、輸入輸出限制 |

Partner/API 不等於本機生成。素材不可外傳時，只能使用有可驗證權重、授權與本機節點的路線；未知就阻擋，不自行安裝或猜測。

### 最小可重現紀錄

```text
created_at 與時區｜ComfyUI release/nightly/commit｜workflow 版本｜完整節點名稱、來源與版本｜實際模型／API｜每份輸入的 SHA-256、職責與權利｜seed 或 unavailable｜輸出設定｜prompt 版本／A-B 標籤｜原始輸出檔｜技術檢查｜創意與聲畫檢查
```

金鑰只放官方登入／憑證機制或環境變數，不寫進 workflow、提示詞、截圖、報告或 Git。若入口不保證 deterministic，seed 只是控制欄位，不宣稱位元級相同。

### 除錯順序

1. 節點是否存在、是否停用、release／nightly 是否不同。
2. ComfyUI、frontend、節點、workflow 與依賴版本。
3. 帳號、credits、網路與安全來源。
4. 模型／API 服務、地區、內容政策、併發與額度。
5. 圖片／影片／音訊格式及實際入口限制。
6. VRAM／RAM（只適用真正本機運算的節點）。
7. 保存錯誤碼、節點名與 request／task ID；不可盲目自動重試。
8. 技術路徑可執行後，才調提示、素材職責、時長、鏡頭與聲音。

## 聲音與後製

### 表演節拍

不要只寫「緊張／開心」。拆成：目標 → 刺激 → 視線反應 → 呼吸／停頓 → 小動作 → 決定 → 行動。每一節拍只安排一個主要變化，寫清對手、視線、走位與最後姿勢。

### 聲音分層

1. 對白或旁白。
2. 人物動作聲。
3. 道具接觸 Foley。
4. 環境底噪／room tone。
5. 音樂功能與節拍。
6. 轉折音效。
7. 左右／遠近與空間方向。

每層記錄來源、權利、出現時間、強弱、方向及是否壓低其他層。AI 生成聲音也是待驗收素材，不自動視為可商用或同步正確。

### 後製與交付順序

原始鏡頭與聲音另存 → 畫面剪輯與連戲 → 對白／聲音同步 → 對白修復 → clip／track 音量 → EQ／dynamics → bus／空間定位 → automation → 文字／品牌後製 → 畫面與聲音技術輸出 → QC → 核准 → 交付。

驗收至少包含：可播放、尺寸／比例、時長、影格／編碼資訊、音軌、對白可懂度、峰值／噪聲、聲畫同步、字幕／文字正確、權利、版本與 SHA-256。

## 4–6 秒短測與 QC

### 單一變數 A/B

1. 選一個會暴露最高風險的 4–6 秒鏡頭。
2. 固定輸入素材、入口版本、畫幅、時長、seed（若有）、角色、場景、聲音與其他設定。
3. A 為目前鎖定基準；B 只修改一個主要變數。
4. 各自保存 prompt、輸出、設定、SHA-256 與 QC。
5. 單次成功只代表該次輸出通過，不升級成模型保證。

### QC 分類與順序

- `identity_drift`：身分／外觀錨點改變。
- `wardrobe_drift`：服裝、配件、道具或材質漂移。
- `spatial_error`：位置、視線、軸線或物件關係錯誤。
- `camera_error`：景別、焦點、路徑、速度或停止點不符。
- `motion_error`：重心、接觸、慣性、節拍或物理錯誤。
- `anatomy_error`：臉、手、肢體、關節或表情結構錯誤。
- `audio_error`：人聲、嘴型、Foley、音樂或同步錯誤。
- `prompt_pollution`：舊案、無關素材、互斥指令或參考職責污染。

先查作品目的／指令遵循，再查結構（時長、空間、動作、鏡頭），接著一致性、聲畫，最後才微調美感。只有看過實際輸出才評動畫、物理與聲畫；只看提示詞時只能標為方案暫評。

### 復原階梯

1. 回到最近鎖定版本，移除舊失敗輸出與無關參考。
2. 從多鏡退回單鏡、長片退回 4–6 秒、多人退回單人。
3. 降低遮擋、逆光、快速轉頭、極端表情與同時接觸物件數。
4. 先通過無聲畫面，再加入對嘴、音樂與同步。
5. 每輪只改一個主變數，建立新版本並保留回退點。

工具不可用或沒有實際輸出時，保存錯誤與最小重試包，狀態用 `blocked`；提示詞、workflow、job ID、預覽、模擬檔或排隊接受都不是 Gate 4 完成證據。
