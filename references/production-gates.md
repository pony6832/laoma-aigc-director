# 製作 Gate

## Gate 1：方向鎖定

- 輸入：創作需求、受眾、目標平台與限制。
- 最低產物：一頁製作 brief，包含目標、訊息、風格方向、預算或時程假設。
- 通過條件：使用者核准方向與限制。
- 停止條件：目標、權利或預算不明。

## Gate 2：角色與影像鎖定

- 輸入：核准 brief、角色或產品參考與視覺方向。
- 最低產物：角色事實、定裝、主視覺及連續性規則。
- 通過條件：身分、定裝、場景與視覺基準均可被驗證。
- 停止條件：參考權利不明，或角色／視覺事實互相衝突。

## Gate 3：導演方案鎖定

- 輸入：已鎖定的角色與影像規格。
- 最低產物：劇本、分鏡、鏡頭清單、生成策略與 QC 計畫。
- 通過條件：每個鏡頭有敘事目的、可執行輸入與連續性檢查點。
- 停止條件：敘事、鏡頭或生成成本尚未核准。

Gate 3 通過前不得進入大量或高成本生成。

## Gate 4：成片驗收

- 輸入：已完成的鏡頭、聲音與後製版本。
- 最低產物：可播放成片、版本紀錄、QC 結果與交付清單。
- 通過條件：內容、連續性、技術輸出與使用者核准均完成。
- 停止條件：關鍵 QC 缺陷、輸出規格不符或核准被撤回。
