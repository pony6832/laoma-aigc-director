# 老馬提示詞資料庫快照

這是使用者指定 Google 試算表於 2026-09-11 的唯讀本地快照。它提供可組裝的提示詞、鏡頭、燈光、照片修復與角色設計材料；不是 ChatGPT 或生成平台的官方斜線指令，也不取代本案已鎖定的角色、場景、權利與技術限制。

## 何時調用

| 任務 | 優先查詢分頁 | 用法 |
|---|---|---|
| 通用整理、決策、腳本、格式或工作流程 | `快捷指令清單` | 依意圖選一個快捷詞，加入背景、限制與輸出格式 |
| 圖像生成或局部編修 | `圖像生成快捷詞（自訂）` | 先找專項快捷詞，再補主體、構圖、光線、比例與禁止項目 |
| 老照片修復、降噪、放大、保留身份或文字 | `照片修復與影像優化提示詞` | 明確分開允許修改、必須保留與禁止新增 |
| 需要完整圖像提示詞骨架 | `完整圖像提示詞案例（長版）` | 只抽取適用段落並替換案件事實，不整段盲貼 |
| 運鏡、速度、路徑、落鏡或鏡頭連戲 | `動態拍攝運鏡提示詞` | 與逐鏡時間、主體動作、起訖構圖及連續性護欄組裝 |
| 光位、光質、色溫、環境光或燈光連戲 | `影片燈光與環境光源提示詞` | 固定世界座標、光向、色溫、曝光、陰影與反射邏輯 |
| 電影級角色設計板 | `雜項紀錄` | 取出角色設計長模板後，填入本案核准角色事實 |
| 不確定分類 | `分類索引` | 先定位類別，再查對應分頁 |

## 查詢方式

從 Skill 根目錄執行：

```powershell
$env:PYTHONUTF8='1'
python scripts/query_prompt_library.py --library references/prompt-library --query "/RESTOREPHOTO" --sheet "照片修復與影像優化提示詞" --limit 3 --json
python scripts/query_prompt_library.py --library references/prompt-library --query "自然窗光" --sheet "影片燈光與環境光源提示詞" --limit 5 --json
```

沒有指定 `--sheet` 時會跨全部分頁查詢；指定不存在的分頁會明確失敗。查詢結果保留來源分頁與列號，方便回查。

## 組裝規則

1. 先套用 `SKILL.md` 的資訊優先序；本資料庫屬於方法與模板，不得覆蓋本次要求或案件鎖定事實。
2. 一次只選最相符的少量紀錄。合併前移除互斥運鏡、光源、比例、動作或保留條件。
3. 把中括號、底線與示例角色替換為本案資料；不得把範例人物、品牌、場景或參數當成已核准事實。
4. 圖片編修固定寫出「允許修改／必須保留／禁止新增」；影片固定補上時間、起訖狀態、連戲與 QC。
5. 涉及目前模型能力、入口、價格、額度或限制時仍須即時查證，不能以本快照作為現況證據。
6. 使用者要求「最新／同步／更新資料庫」時才重讀原試算表；平常使用本地快照，確保可重現。
