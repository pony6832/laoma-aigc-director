# AI 導演提示詞檢查清單（送出前內部檢查）

來源：整理自 openailearning Instagram 貼文〈How to Prompt Like an AI Filmmaker〉（作者 Shailesh，2026-10-01，https://www.instagram.com/p/Dd-lvRwzkq4/），含說明文字與資訊圖，繁中改寫。

## 用法

交付任何 AI 影片或影像生成提示詞之前（T2V、I2V、首尾幀、Seedance、H3、Veo、Kling、ComfyUI、分鏡圖提示等），逐鏡在內部跑一遍本清單：

- 缺項就補；補不了而且會影響結果的，列進交付說明的「待決定」，不要自行編造會改變作品方向的事實。
- 不必把整份清單貼給使用者。交付時用一行說明「已依導演清單檢查」，並列出補上或刻意省略的項目。
- 平台或技能自己的格式（例如 H3 的欄位結構、案件鎖定條件）優先；本清單只檢查內容是否完整，不改變輸出格式。

## 核心論點

提示詞只描述氛圍（「電影感男人跑過城市，寫實，4K」）就會失敗。提示詞必須「導演」一個鏡頭，回答九個問題：觀眾該注意什麼、畫面裡有誰、具體在做什麼、攝影機在哪、用什麼鏡頭、演員怎麼表演、光從哪來、什麼會對動作產生物理反應、鏡頭從哪開始在哪結束。

框架：意圖 → 主體＋動作 → 畫面 → 光學 → 攝影機 → 表演＋物理 → 光線＋空間 → 連續性

## 八步檢查

1. **意圖**：能用一句話說出這個鏡頭的功能（揭露資訊、製造緊張、展現規模、捕捉反應）；後面每個攝影選擇都回扣這個目的。
2. **主體＋動作**：寫清楚有誰；動作是可觀察的行為，不寫情緒標籤（不寫「很害怕」，寫「門口僵住、眼睛轉向聲源、肩膀繃緊、慢慢後退」）；交代走位與移動方向。
3. **畫面**：指定景別且符合意圖（遠景＝地理與規模、中景＝動作與關係、特寫＝情緒與反應、插入＝關鍵細節）；角度、高度、構圖只在有理由時寫；只用一種構圖策略。
4. **光學**：焦段有理由（24mm 環境／速度、35mm 自然空間、50mm 人眼、85mm 壓縮／親密、微距＝質感）；需要時寫景深與透視。不因為「聽起來很電影」而加。
5. **攝影機**：一個鏡頭只有一種有動機的運鏡（固定、推、拉、跟、搖、手持、升降、環繞、移焦）；運鏡指令不互相衝突。
6. **表演＋物理**：視線、呼吸、猶豫、表情；姿態、重心、腳步著地、節奏；動量、失衡與恢復；衣物頭髮反應；物件互動與環境的物理反應。（「跑得很快」→「加速、半步打滑、穩住重心後繼續跑」）
7. **光線＋空間**：光有動機（光源與方向）；軟光或硬光、對比；場景實際光源；只寫重要的環境細節；寫真實材質與質地。
8. **連續性**：起始與結束狀態；角色、服裝、道具一致；地點與光線邏輯一致；畫面方向與視線一致；道具、傷勢、損壞狀態延續。

## 模式規則

- **T2V**：全部描述。`[FRAME + OPTICS] of [SUBJECT + ACTION] in [SPACE], [CAMERA]. [PERFORMANCE + PHYSICS]. [LIGHT + MATERIAL]. [CONTINUITY / END STATE].`
- **I2V**：只寫動作，不重述圖中已有的主體、風格、構圖。`[CAMERA MOTION] as [SUBJECT ACTION]. [PERFORMANCE + SCENE MOTION + TIMING]. [CONTINUITY / END STATE].`
- **只寫看得見的面**（I2V 與關鍵幀都適用）：提示詞寫到的每個動作或畫面變化，都要發生在這個機位看得見的表面上。故事需要畫面外的內容（背對鏡頭的螢幕、正在讀的信）時，改寫主角的反應或它投出的光，並寫明可見面的狀態（例：「筆電背蓋保持素面」）；過肩或反拍決定裝置哪一面入鏡。光也一樣：寫光的效果（側逆光、窗光落在臉上），不要點名畫面外的燈具，生成器會把提到的燈具畫進畫面。
- **一鏡一拍**：每次生成 5–10 秒，一個主要動作或簡單推進；不塞多機位、多動作、換景；需要剪接就拆鏡頭；連續動作寫清楚先 X、再 Y、最後 Z。
- **迭代順序**：一次只改一個變數。動作 → 機位（景別／鏡頭／攝影機）→ 表演＋物理 → 光線＋環境 → 連續性＋結束狀態。

## 送出前排除

- 只堆形容詞（cinematic、epic、8K）、模糊的動作與情緒
- 運鏡衝突、一鏡多動作、沒有表演指導、忽略物理與物件互動、忽略比例
- 隨意堆砌場景、無動機的光線變化、忘記畫面方向、與前一鏡不一致
- 過度指定：相機品牌名、塞滿構圖規則、不必要的技術術語、參考圖已有的細節
