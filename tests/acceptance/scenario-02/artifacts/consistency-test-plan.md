# 4–6 秒一致性短測規格（尚未生成）

- 測試時長：5 秒，符合 4–6 秒範圍。
- 單一主要動作：小狐狸從靜止姿勢走兩步後停下，一手扶住黃色小包背帶。
- 單一主要運鏡：固定中全景，不加環繞、快速推拉或剪接。
- 固定條件：同一角色、耳朵輪廓、藍雨衣、黃色小包、無角色場景板的光向與 9:16。
- 起點／終點：正面偏四分之三站立 → 走兩步 → 站穩且小包仍在同一側。
- QC：身分、耳朵、服裝、背帶接觸、手部、重心、地面接觸、光向與最後姿勢。
- 通過條件：實際可播放 4–6 秒檔案、真實時長、入口與設定紀錄、SHA-256、逐項 QC 與核准；prompt 或 job ID 不算輸出。
