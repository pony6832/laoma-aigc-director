# Seedance Generation Plan v01（未執行）

## 入口與規格邊界

- 指定平台族：Seedance；不混入 H3、ComfyUI 或其他平台欄位。
- 目標交付：三段各 5 秒、16:9，剪輯後 15 秒。
- 待執行時重查：實際入口、模型名稱與版本、可選解析度、素材限制、地區、費用與輸出格式。
- Gate 條件：只有 Gate 3 方案獲核准、外部 Gate 2 鎖定雜湊可驗證、入口與成本確認後才送出。

## 共用鎖定內容

同一隻已核准小狐狸；同一耳朵輪廓、藍雨衣、黃色小包與雨巷；16:9；冷藍雨後光線逐步由街燈暖光接管。參考圖只負責角色身分／定裝，不自動轉移背景、文字或品牌。

## 逐鏡可執行輸入

- `S001_v01_seedance`：固定中全景；小狐狸發現打轉紙船，視線先到、身體後蹲；右手停在船上方；紙船向右開始移動；禁止手船交疊，結尾保持可接走路姿勢。
- `S002_v01_seedance`：側向中全景；角色先沿水溝左向右走兩步，鏡頭晚半拍平移；一手遮開水滴但不抓船；黃色小包同側；結尾角色站穩、紙船進亮區。
- `S003_v01_seedance`：固定中景；角色先目送紙船、停頓、再回頭；街燈只在回頭後亮；冷暖光過渡，微笑後穩定停住。

## 檔名與紀錄

生成檔名使用 `<shot>_<version>_seedance_<take>`；每次保存入口、模型顯示名稱、設定、輸入素材 SHA-256、實際輸出 SHA-256、時間與 QC。排隊畫面或 job ID 不算輸出。

## QC／停止規則

逐鏡檢查身分、耳朵、雨衣、小包、手船接觸、空間方向、光線事件、起迄姿勢與聲音點。失敗先標籤，再回最近鎖定版，只重試該鏡且一次改一個主變數。
