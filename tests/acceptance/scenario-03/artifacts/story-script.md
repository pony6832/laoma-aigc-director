# 雨巷紙船｜15 秒故事／劇本 v01

## 核心

小狐狸不是拯救者，而是短暫陪伴者；燈亮的瞬間讓「護送」轉成「被回應」。全片無對白，避免引入未核准聲線。

## 三段劇本

1. **00:00–00:05｜發現**：雨後巷內，小狐狸先停步，視線落到積水邊打轉的紙船。牠微微蹲下，右手停在紙船上方但不碰觸。結尾為紙船順水開始移動。
2. **00:05–00:10｜護送**：小狐狸沿水溝側邊慢走，保持黃色小包在同一側；紙船由畫面左向右前進。牠用手遮開一滴落水，而非抓住紙船。結尾為紙船進入較亮水面。
3. **00:10–00:15｜回望**：小狐狸停步、先看紙船離開，再回頭；街角燈在回頭後才亮起。暖光接住藍雨衣輪廓，牠短暫微笑，停在可銜接片尾的穩定姿勢。

## 聲音節拍

雨滴與細水流連續；第二鏡加入輕鞋步與布料聲；第三鏡燈亮配低音量電氣啟動聲，再落一個溫暖單音。沒有旁白、品牌音或未授權音樂。
