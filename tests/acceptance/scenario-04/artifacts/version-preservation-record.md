# Version Preservation / Rollback Record

## 保留範圍

| 鏡頭 | 動作 | 現況證據 |
|---|---|---|
| S001 | 不讀寫、不生成、不替換 | 原檔與原 SHA-256 未提供；執行時先讀取並在前後比對 |
| S002 | 保留 v01，只允許新增 v02 | 本次只建立提示詞；沒有媒體輸出或替換 |
| S003 | 不讀寫、不生成、不替換 | 原檔與原 SHA-256 未提供；執行時先讀取並在前後比對 |

## 替換條件

1. 複製或引用 S002 v01，不覆蓋原檔。
2. 產生新檔 `S002_v02_seedance_takeNN` 並計算 SHA-256。
3. 單鏡 QC 通過手船間隙、手部解剖、方向、角色與光線連戲。
4. 比對 S001、S003 前後雜湊完全相同。
5. 使用者核准後才更新剪輯引用；若失敗，仍引用 S002 v01 並保留失敗輸出與記錄。

目前 `replacement_performed=false`、`rollback_needed=false`；原因是沒有執行生成或修改。
