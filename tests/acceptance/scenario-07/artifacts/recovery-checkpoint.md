# Recovery Checkpoint

1. 讀取原案 `PROJECT_STATE.json`，驗證 Gate 3 鎖定產物與 SHA-256；不修改原檔。
2. 建立獨立重試目錄與版本，記錄工具、工作流、模型和環境。
3. 用 5 秒、單一動作、固定鏡位規格重現；若啟動仍失敗，只改一個診斷變數。
4. 有實際輸出後計算 SHA-256，檢查可播放性、時長、角色、動作、構圖、光線與結尾姿勢。
5. 未通過則保留失敗輸出／日誌並回到本 checkpoint；不覆蓋鎖定版本。
6. 原入口確定不可恢復時，列出替代入口、資料外傳、成本與參數差異，等待使用者核准；未核准不切換。
7. 只有實際輸出通過單鏡 QC 並留下工具證據後，才可把新版本納入後續 Gate 4。
