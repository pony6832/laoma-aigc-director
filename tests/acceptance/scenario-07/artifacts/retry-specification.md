# Minimal 5-second Retry Specification

- 目的：驗證工具可啟動、模型可載入並產生一個可播放輸出；不追求成片品質。
- 時長：5 秒。
- 主體：沿用 Gate 3 已鎖定角色／物件；不在本文件重寫身分事實。
- 單一主要動作：站定後緩慢轉頭一次。
- 單一主要運鏡：固定中景。
- 固定條件：原畫幅、角色、服裝、場景、光線、入口與已核准基礎設定。
- 第一次重試只處理工具／模型可用性，不同時升解析度、換模型、加角色或加複雜動作。
- 成功證據：命令與 exit code、實際非空媒體、可解析時長、輸出 SHA-256、工具／模型版本及單鏡 QC。
- 失敗處理：保存真實 stderr；以 `tool_error`、`model_missing`、`memory_error` 或 `workflow_error` 分類後，一次只改一個原因。
